# Видео для ProductShowcase

Поместите видео файлы в эту папку со следующими именами:

1. `main-product-video.mp4` - основное видео для главного продукта
2. `secondary-product-1.mp4` - видео для первого второстепенного продукта
3. `secondary-product-2.mp4` - видео для второго второстепенного продукта
4. `secondary-product-3.mp4` - видео для третьего второстепенного продукта

Рекомендации по видео:
- Формат: MP4 (H.264)
- Разрешение: 1920x1080 или выше
- Длительность: 10-15 секунд
- Размер файла: до 10 МБ для оптимальной загрузки
- Без звука (автоматически воспроизводятся без звука)

Также можно добавить постеры для видео:
- `placeholder-video-poster.jpg` - общий постер для всех видео
